# 一期一会 — コンセプト

## 社会的意義

このアプリの最大の特徴は、**メッセージを読むために現地に赴く必要がある**という点にある。

写真と文字を眺めるのではなく、受け取る側も同じ場所に立ち、同じ風景を見る。もちろん、同じ場所でも季節・天気・時間帯・心境が違えば、相手と完全に同じ体験にはならない。それでも「同じ地点に立つ」というだけで、文字や写真からは届かない情報が入ってくる。

このアプリが提供しているのは、**相手の体験を追体験する手がかり**である：

- 同じ場所・同じ景色の中でメッセージを受け取ることで、文章だけでは伝わらない文脈に触れられる
- 自分が現地で感じたことと、相手が残したメッセージを照らし合わせることで、理解の糸口が生まれる
- あるいは、同じ場所でも自分とは違う感性を持つ人がいることに気づく

完全な相互理解は保証されない。だが、画面の中だけで完結する情報交換よりは、ずっと**身体的で具体的な関わり**が生まれる。

## SNSへの新しいアプローチ

インターネットは人と人をつなぐ一方で、傍観者を量産してきた側面がある。タイムラインをスクロールするだけで、誰かの人生を「見た気」になれる。

一期一会は、その構造に対するひとつのアンチテーゼである。メッセージを受け取りたければ、舞台に上がらなければならない。

- デジタル上のやりとりが、物理空間での行動を促すキッカケになる
- 見るだけの傍観者ではなく、自ら足を運ぶ参加者であることを求める

これが既存のSNSを置き換えるとは考えていない。むしろ、TwitterやInstagramのような汎用的なプラットフォームとは別の軸として、**もう一つの関わり方の選択肢**を提示するものとして位置づけている。

汎用SNSが「広く・速く・多く」なら、一期一会は「狭く・遅く・深く」。誰でも気軽に使えるアプリではないかもしれないが、その不便さこそが価値になりうる。

## タイムカプセルとしての側面

このアプリは、個人にとって**場所に埋められたタイムカプセル**でもある。

メモ帳やnoteなど、自分の記録を残す手段は多い。しかし、それを後から見返すことは少ない。確認する行為が面白いとわかっていても、なんとなく手が動かない。「見返す」という行為には、それ自体を引き起こすキッカケが必要なのだ。

一期一会のコンセプトは、そのキッカケを設計の中に組み込んでいる。**メッセージを保存する際に任意の日時を指定でき、その日になると通知が届く**仕組みである。

通知を受け取る → 現地へ向かう → 同じ景色をシャッターに収める → かつて自分が残したメッセージが現れる。

この流れは、現実のタイムカプセルそのものだ：

- 任意の日時指定 = **埋めるとき**
- 通知 = **開けるべき合図**
- 現地に赴いてシャッターを切る = **掘り起こす行為**

デジタルでありながら、開封には物理的な移動を要求する。これが一期一会の独自性である。

この仕組みは、自分自身に対する記録だけでなく、他者との関わりにも広がる。たとえば友人に「来年の同じ日に開けて」とメッセージを残せば、その日に相手の通知が鳴り、相手は現地に足を運ぶ。

普通のSNSにはない**時間軸の使い方**であり、デジタル上の関わりに儀式性を取り戻す試みでもある。
